DeepSea Expeditions — User Stories
1. Visitor (public user)
ID	User story
US01	As a visitor, I want to browse available expeditions so that I can learn about deep-sea exploration.
US02	As a visitor, I want to view mission details so that I can understand each expedition's objectives and progress.
US03	As a visitor, I want to explore discovered marine species so that I can learn about underwater biodiversity.
US04	As a visitor, I want to browse scientific discoveries so that I can learn about expedition findings.
US05	As a visitor, I want to view expedition photographs and videos so that I can experience underwater exploration.
US06	As a visitor, I want to read and download mission reports so that I can access scientific findings.
US07	As a visitor, I want to view submarine and equipment information so that I can learn about exploration technology.

2. Registered User
ID	User story
US08	As a user, I want to register an account so that I can access personalized features.
US09	As a user, I want to log in and log out securely.
US10	As a user, I want to view and update my profile so that my information stays current.

3. Researcher
ID	User story
US11	As a researcher, I want to view my assigned missions so that I can track my expedition participation.
US12	As a researcher, I want to create scientific reports so that I can document my findings.
US13	As a researcher, I want to edit my reports so that I can correct or update scientific information.
US14	As a researcher, I want to upload expedition photographs and videos so that I can share research media.
US15	As a researcher, I want to view discoveries associated with my missions so that I can follow their scientific outcomes.

4. Administrator
ID	User story
US16	As an administrator, I want to manage user accounts so that I can control platform access.
US17	As an administrator, I want to create, edit, and delete missions so that expedition information stays updated.
US18	As an administrator, I want to manage submarines and locations so that mission resources are organized.
US19	As an administrator, I want to manage researchers and assign them to missions.
US20	As an administrator, I want to manage equipment so that available resources are tracked.
US21	As an administrator, I want to manage discoveries and species so that the scientific database stays accurate.
US22	As an administrator, I want to manage mission reports and expedition media so that published content is maintained.
